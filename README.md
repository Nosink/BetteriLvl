# BetteriLvl

Lightweight WoW addon that displays item information directly on your character and inspect frames.

## Features

- Per-slot item level labels for your character and inspect target.
- Quality-colored borders for your character and inspect target.
- Durability display on character equipment slots.
- Durability display as text or a bar, with optional percentage coloring.
- Separate settings for player and target overlays.

## Usage

- Open options: /betterilvl or /bilvl, or via Interface -> AddOns.
- Equip or change items to refresh character overlays automatically.
- Inspect a target to populate its equipment overlays.
- Change settings to update overlays immediately; a reload is not required.

## Commands

- /betterilvl - open the options panel
- /bilvl - shortcut to the same options

## Notes

- Inspect values appear after INSPECT_READY; a brief delay is normal.
- Durability can be switched between text and bar display while the addon is running.
- Disabled overlays are hidden immediately.
